# 1 导出

## 1.1 文档

### 1.1.1 源文件PDF（不含笔记）

当学习者需要将原本的文档导出时，可以点击文档右下角的“...”更多按钮后在弹出的子菜单轻点“导出源PDF文件

![动图演示：导出源 PDF 文件](<image/gif-2024-04-19 at 21.48.04_AqfsfSrI3N.gif>)

<p class="mn-image-caption">动图演示：导出源 PDF 文件</p>

### 1.1.2 导出压平PDF（含有笔记）

<div class="mn-callout mn-callout--tip">
  <span class="mn-callout__icon" aria-hidden="true">💡</span>
  <div class="mn-callout__body">导出的压平PDF中的笔记内容不支持在任何软件编辑（含MarginNote），且目前导出压平PDF不含有在MarginNote中制作的目录</div>
</div>

当学习者需要将含有笔记的文档导出时有两种方式：

<ol markdown="1">
<li markdown="1">

点击文档界面右上角的`文档-更多`按钮，点击`导出文档`即可将文档导出为压平PDF或长图

![点击文档界面右上角的文档-更多按钮，点击导出文档](image/导出压平PDF-文档入口.png)

<span class="mn-image-caption">点击文档界面右上角的文档-更多按钮，点击导出文档</span>

</li>
<li markdown="1">

点击学习集界面右上角`学习集-更多`-`导出学习集-导出文档`

![点击学习集界面右上角学习集-更多-导出学习集-导出文档](image/导出压平PDF-学习集入口.png)

<span class="mn-image-caption">点击学习集界面右上角学习集-更多-导出学习集-导出文档</span>

</li>
<li markdown="1">

选择需要导出的页面。可通过选择 缩略图、`目录`、`页码范围`或`标注`选择导出页面（4.4.4 及后续版本支持）。

![选择需要导出的页面](image/选择导出页面.png)

<span class="mn-image-caption">选择需要导出的页面</span>

<ul markdown="1">
<li markdown="1">

`目录`：可以选择目录中的具体节点以导出

![目录：可以选择目录中的具体节点以导出](image/按目录选择导出页面.png)

<span class="mn-image-caption">目录：可以选择目录中的具体节点以导出</span>

</li>
<li markdown="1">`全部页面`：选择后将导出全部页面，不包含折叠的页面</li>
<li markdown="1">`页码范围`：可以选择部分页码导出，以逗号分隔开（不区分中英文标点），例如 “1,3,5-6”，选择后将导出第1 页、第3 页、第5 页到第6 页</li>
<li markdown="1">`标注`：点击将选择所有包含笔记的页面</li>
</ul>

</li>
</ol>

<div class="mn-callout mn-callout--info">
  <span class="mn-callout__icon" aria-hidden="true">ⓘ</span>
  <div class="mn-callout__body">关于导出留白：如果想导出留白，需要将留白设置为展开，目前导出缩略图中不展示留白</div>
</div>

## 1.2 脑图

### 1.2.1 导出分支为PDF 格式（4.4.4 及以后版本支持）

单击想导出的分支的**最上级卡片**，在弹出菜单栏中切换到`高级`，选择`导出分支`或者`导出本卡`，详见下面的介绍。

![选择导出分支或者导出本卡](image/导出分支入口.png)

<p class="mn-image-caption">选择导出分支或者导出本卡</p>

#### 1.2.1.1 导出分支

选择`导出分支`后，会根据节点层级和疏密程度自动分页，可以进一步调整PDF的信息密度，包含宽松、均衡、紧凑和经典脑图（卡片密度从小到大排列）

![导出分支](image/导出分支密度选项.png)

<p class="mn-image-caption">导出分支</p>

导出示例：

![导出示例](image/导出分支-宽松.png)

<p class="mn-image-caption">导出示例</p>

![导出示例](image/导出分支-经典脑图.png)

<p class="mn-image-caption">导出示例</p>

#### 1.2.1.2 导出本卡

进一步可以选择导出为 `PDF` 或者`长图`，导出本卡仅包含单张卡片

![导出本卡](image/导出本卡.png)

## 1.3 学习集

点击`学习集-更多`-`导出学习集`

![点击学习集-更多-导出学习集](image/导出学习集选项.png)

<p class="mn-image-caption">点击学习集-更多-导出学习集</p>

`导出备份`选项卡下有`导出学习集备份`以及`导出到笔记数据库`

<ol markdown="1">
<li markdown="1">`导出学习集备份`：可以导出当前学习集的所有文档与笔记数据用于分享或者备份，备份文件仅可以用Marginnote打开</li>
<li markdown="1">

`导出到笔记数据库`：多笔记数据库Max专属功能，通过将部分学习集导出到其他笔记数据库可以方便的让我们将学习集在不同数据库间转移，可用于不同时期，不同领域的笔记数据隔离。

<div class="mn-callout mn-callout--tip">
  <span class="mn-callout__icon" aria-hidden="true">💡</span>
  <div class="mn-callout__body">关于笔记数据库的使用用法与常见场景详见<a class="mn-preview-link" href="../note-database-creating-managing-databases/" title="笔记数据库①：新建和管理数据库" data-preview="笔记数据库①：新建和管理数据库">笔记数据库①：新建和管理数据库</a></div>
</div>

</li>
</ol>
