# 新建文本框/图片/拍照

<div class="mn-callout mn-callout--tip">
  <span class="mn-callout__icon">💡</span>
  <div class="mn-callout__body">
    <p><code>文本框</code> - <strong>就地标注</strong>：在原文旁边写补充、重点、疑问，避免把想法散落在别处。</p>
    <p><code>图片</code><strong> </strong>-<strong> 讲解流程</strong>：插入截图/示意图并可改大小、复制、剪切、删除，信息更清晰。</p>
    <p><code>拍照</code><strong> </strong>- <strong>课堂、会议、图书学习的即刻记录</strong>：把纸页、白板等现场拍下，直接存为文档图片或脑图卡片。</p>
    <p>在同一页把自己的想法、图像和实时内容连在一起，阅读效率更高、复习更快、分享更清晰。</p>
  </div>
</div>

# 2 在文档和脑图中添加图片

## 2.1 在文档中添加图片

<a class="mn-preview-link" data-preview="图片" href="https://www.wolai.com/sujPUshdvjce3pNeqVsyYf" title="图片">图片</a>

有三种方式可以添加图片：

- 操作一：**最简便** - 从外部 APP直接拖入：iPad 分屏/Mac 端多窗口情况下，可直接将其他软件内的图片直接拖入 MarginNote文档。
- 操作二：点击文档顶部导航栏中的`图片`按钮（如上方图标所示），在需要的位置单击，然后选择本地相册里的图片，即可插入。

    <span class="mn-image-caption">操作二：点击文档顶部导航栏中的图片按钮（如上方图标所示），在需要的位置单击，然后选择本地相册里的图片，即可插入。</span>
- 操作三：在文档空白处长按/右键呼出弹出菜单栏，点击`图片`按钮。
    ![](image/image_ChbudPtgFc.png.mark.png)
    <span class="mn-image-caption">操作三：在文档空白处长按/右键呼出弹出菜单栏，点击图片按钮。</span>

## 2.2 在脑图中添加图片为卡片

有两种方式可以在脑图中添加`图片`：

- 操作一：**最简便** - 从外部 APP直接拖入：iPad 分屏/Mac 端多窗口情况下，可直接将其他软件内的图片直接拖入 MarginNote脑图。
- 操作二：直接粘贴系统粘贴板内的图片到脑图（Command+V），即可在脑图中创建为带图片的新卡片。
    ![](image/image_3tg9pIV00G.png.mark.png)
    <span class="mn-image-caption">操作二：直接粘贴系统粘贴板内的图片到脑图（Command+V），即可在脑图中创建为带图片的新卡片。</span>

# 3 在文档和脑图中拍照

<div class="mn-callout mn-callout--tip">
  <span class="mn-callout__icon">💡</span>
  <div class="mn-callout__body"><p>MarginNote 中的相机会自动使用<strong>连续扫描仪</strong>选取视野中有用的内容进行拍照；学习者也可以自己点击拍照按钮进行拍照。</p></div>
</div>

## 3.1 在文档中拍照，插入为图片

<a class="mn-preview-link" data-preview="相机" href="https://www.wolai.com/tN9K5fiLSVpNBGMY8GV6La" title="相机">相机</a>

在文档空白处长按/右键呼出弹出菜单栏，点击`相机`按钮（如上方图标所示），即可拍照；对照片的操作与上述文档里`图片`一致。

![](image/image_0tq3CZ1bkI.png.mark.png)

<p class="mn-image-caption">在文档空白处长按/右键呼出弹出菜单栏，点击相机按钮（如上方图标所示），即可拍照；对照片的操作与上述文档里图片一致。</p>

![可在工具-自定义中选择需要的图标加入一级菜单。 可在工具-自定义中选择需要的图标加入一级菜单。 ](image/image_j5tFaMXFrI.png.mark.png "可在工具-自定义中选择需要的图标加入一级菜单。 可在工具-自定义中选择需要的图标加入一级菜单。 ")

<p class="mn-image-caption">可在工具-自定义中选择需要的图标加入一级菜单。</p>

## 3.2 在脑图中拍照，保存为卡片

1. 在脑图空白处点击呼出弹出菜单栏，点击`相机`图标，即可拍照。
    ![](image/image_3tg9pIV00G.png.mark.png)
    <span class="mn-image-caption">在脑图空白处点击呼出弹出菜单栏，点击相机图标，即可拍照。</span>
2. 拍照后单张照片/多张照片会保存为一张卡片。
    ![](image/E43C7D62-7963-406B-925C-679AD5112C1B_1_102_o_WWk_x.jpeg)
    <span class="mn-image-caption">拍照后单张照片/多张照片会保存为一张卡片。</span>
3. 每张照片为一条评论，可在卡片编辑器中调整照片顺序。
    ![](image/image_2IKh7AcKNR.png)
    <span class="mn-image-caption">每张照片为一条评论，可在卡片编辑器中调整照片顺序。</span>
